# 2026-09-19 文件区栏收割补收与面板按栏分组

## 需求

1. 文件区栏(`OverviewRepoFiles-module__Box_3 > nav > ul`)的其余项
   (Settings 等,在 More 下拉内)仍未收割进面板。
2. 面板条目按各自所属的栏,用轻微分割线分组。

## 根因定位

**收割一次性失败即永久缺失**:收割缓存以"路径 + 视口桶"为键。首轮(常见
于注水前)文件区 More 触发器不可见/收割为空时,该栏结果不入 Map;但缓存
一旦建立(其他栏有收获),后续重建全部命中缓存,文件区栏永远不再被重试。
这正是"只有可见 README,溢出项收不到"的机制性原因。

## 修改内容

1. 快照检查点 `782d801`。
2. **缺栏补收**:
   - 收割循环把"收割为空/失败"的栏记录为 `missedBars`(与收获结果一起
     入缓存,不缓存空 Map 语义保持);
   - 每轮构建开始时,从缓存取出最多 2 个缺栏重点重试;成功则写入 Map,
     失败/仍空则留在 `missedBars` 由下一轮继续(有界节奏,不狂点触发器);
   - `harvestMoreItems` 本身带点击→等菜单→Escape→复位的安全时序。
3. **按栏分组**:
   - `collectRepoHomeNavItems` 为每条条目记录 `barKey`/`barLabel`
     (aria-label 优先,回退首个锚点文本);
   - `buildNavDockPanel` 渲染时跨栏插入 `.mgga-nav-dock-divider`
     (1px 主题自适应分隔线 + 11px 栏名小标题,首个条目前不加);
   - 分割线带守卫属性,不触发 observer 自循环。
4. 面板结构版本 v4 → v5 强制重建;版本 2026.9.31,update_log 同步。

## 验证

- `node --check` 语法通过(0 错误)。
- git diff 复查:missedBars 记录/补收节奏、barKey/barLabel 采集、分割线
  渲染与样式、结构版本号五处改动与计划一致;补收仅在缓存键匹配时进行,
  视口桶变化仍走全量重收割。
- 实机预期:面板出现分组——仓库标签条组(Code/Issues/PR/Actions/…+ 其
  溢出项)、文件区组(README + Settings 等 More 溢出项,经 1-2 轮补收后
  出现);组间有轻分割线与栏名。
